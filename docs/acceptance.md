## 4. 对外 API 面与 react-okr-tree 的对齐（2026-09-21 双向差集实测）

比对方法：props 取 `require('./dist/vue3-okr-tree.cjs').VueOkrTree.props` 的键全集，与 react 侧 `packages/react-okr-tree/src/OkrTree.tsx:59-191` 的 `OkrTreeProps` 字段做双向差集；导出面取两边 `dist/*.cjs` 的 `Object.keys()`。

| 对比                   | 结果                                                                                                                                                                                                                                                                                                                                                 |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| props 数量             | vue3 **40** 个 ↔ react **60** 个                                                                                                                                                                                                                                                                                                                     |
| 仅 vue3 有（react 缺） | **空集**。40 个 prop 逐个在 react 存在，含原版两处拼写 `currentLableClassName`、`showCollapsable` 两边一致                                                                                                                                                                                                                                           |
| 仅 react 有            | 20 个，全部是框架映射而非新增能力：12 个 emits → 12 个 `on*` 回调（逐条 1:1，`node-click`→`onNodeClick` … `node-drop`→`onNodeDrop`）；`onExpandedKeysChange` / `onCurrentKeyChange`（D3 受控写法）；`renderNode` / `renderExpandBtn` / `empty` / `children`（D4 插槽改 render props）；`className` / `style`（requirements 4.1 明写的 React 侧透传） |
| 导出面                 | vue3 **17** 个 ↔ react **19** 个。仅 vue3：`createTypedOkrTree`（react 按 D5 移除）、`VueOkrTree` 与 `VueOkrTreePlugin`（按 D6 移除，默认导出改为 `OkrTree`）。仅 react：`BUILT_IN_THEMES`、`DEFAULT_PROPS`、`resetNodeIdSeed`、`resetWarnings`、`warn`                                                                                              |
| 结论                   | **功能面已对齐，无漂移**                                                                                                                                                                                                                                                                                                                             |

> ⚠️ 这次比对顺带暴露本仓库一处文档不准：react 侧审计的 G6 指出 `requirements.md` 4.7 声称 `BUILT_IN_THEMES`「对齐 `src/lib/index.ts`」，但 vue3 入口实测 17 个导出里**并没有它**。要么补导出，要么改措辞——见第 6 节 G7。
